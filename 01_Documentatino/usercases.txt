@startuml
' Cas d'utilisation
skinparam actorStyle awesome
left to right direction

actor "Visiteur" as Guest
actor "Membre connecté" as Member
actor "Maker" as Maker
actor "Administrateur" as Admin

package "Plateforme Je Demain" {
    ' --- Accessible sans connexion ---
    usecase "Consulter l'annuaire des FabLabs" as UC_Directory
    usecase "Consulter l'agenda (événements)" as UC_Agenda
    usecase "Rechercher (solutions / besoins)" as UC_Search
    usecase "Consulter les solutions" as UC_Browse
    usecase "Consulter un profil public" as UC_Profile
    usecase "S'inscrire (avec consentement)" as UC_Register
    usecase "Se connecter" as UC_Login

    ' --- Réservé aux membres connectés ---
    usecase "Déposer un besoin (+ fichiers)" as UC_Submit
    usecase "Publier une solution (+ fichiers)" as UC_Publish
    usecase "Commenter une solution" as UC_Comment
    usecase "Signaler un contenu" as UC_Report
    usecase "Proposer un événement" as UC_AddEvent
    usecase "Consulter mon tableau de bord" as UC_Dashboard
    usecase "Se proposer sur un besoin (candidater)" as UC_Apply
    usecase "Valider un maker (mon besoin)" as UC_Validate

    ' --- Administration ---
    usecase "Voir les statistiques" as UC_Stats
    usecase "Modérer les signalements" as UC_ModReport
    usecase "Modérer les commentaires" as UC_ModComment
    usecase "Supprimer un contenu" as UC_Delete
}

' Le membre connecté hérite des actions du visiteur
Guest <|-- Member
Member <|-- Maker
Member <|-- Admin

Guest --> UC_Directory
Guest --> UC_Agenda
Guest --> UC_Search
Guest --> UC_Browse
Guest --> UC_Profile
Guest --> UC_Register
Guest --> UC_Login

Member --> UC_Submit
Member --> UC_Publish
Member --> UC_Comment
Member --> UC_Report
Member --> UC_AddEvent
Member --> UC_Dashboard
Member --> UC_Validate

Maker --> UC_Apply

Admin --> UC_Stats
Admin --> UC_ModReport
Admin --> UC_ModComment
Admin --> UC_Delete

note bottom of UC_Report
  Signalement contextuel : solution, besoin,
  commentaire, événement ou profil.
end note
@enduml
